# Contributing

## Setup

- Rust with the `wasm32v1-none` target, `stellar-cli`, and Node 22.
- `cargo test` runs both contracts inside the Soroban host.
- `cd app && npm ci && npm test` runs the CLI tests; they need no network and no keys.
- `scripts/build.sh` runs both suites and builds the wasm files.

## Pull requests

- One change per pull request, with tests for new behaviour. Every contract auth rule
  has a negative test using explicit `mock_auths`; keep it that way.
- Contract changes must update `ARCHITECTURE.md` and keep `test_snapshots/` in step
  (they are regenerated by `cargo test`).
- Commit messages are short and conventional (`feat:`, `fix:`, `docs:`, `ci:`).
- CI must pass: `cargo test` and `npm test`.

## Scope

Money-moving rules live in `contracts/`. The CLI and ledger page only build
transactions and read state; they must never hold or custody funds.
